# fairyland-legal

Masallar Diyarı / Fairyland uygulamasının resmi belgeleri.

## İçerik

- `index.html` — Ana sayfa, tüm belgelere link
- `privacy-policy-tr.html` — Gizlilik Politikası (Türkçe)
- `privacy-policy-en.html` — Privacy Policy (English)
- `kvkk-tr.html` — KVKK Aydınlatma Metni
- `terms-tr.html` — Kullanım Şartları (Türkçe)
- `terms-en.html` — Terms of Use (English)

## Yayınlama

Bu klasör GitHub Pages için tasarlanmıştır. Aşağıdaki URL'lerle erişilebilir olur:

- `https://<github-kullanici-adin>.github.io/fairyland-legal/`
- `https://<github-kullanici-adin>.github.io/fairyland-legal/privacy-policy-tr.html`
- `https://<github-kullanici-adin>.github.io/fairyland-legal/kvkk-tr.html`
- vs.

## App Store Connect'te kullanılacak URL'ler

- **Privacy Policy URL** (zorunlu): `https://<kullanici>.github.io/fairyland-legal/privacy-policy-en.html`
- **Terms of Use URL** (opsiyonel): `https://<kullanici>.github.io/fairyland-legal/terms-en.html`
- **Support URL** (zorunlu): `https://<kullanici>.github.io/fairyland-legal/` (ana sayfa, iletişim bilgisi var)

## Güncelleme

Bir belgeyi güncellemek için ilgili HTML dosyasını düzenle ve yeni commit at — GitHub Pages 1-2 dakika içinde yeniden yayınlar.

Bilgi: tarihler ve iletişim e-postası her dosyanın altında ayrı ayrı belirtilir.
